# NODO Business Club

Espacio de coworking premium diseñado para profesionales que buscan inspiración, conexión y crecimiento.

## Descripción

NODO Business Club es un espacio de trabajo flexible ubicado con vistas al mar, diseñado para profesionales independientes, teletrabajadores y empresas que buscan un entorno de trabajo de calidad.

### Espacios disponibles:
- **The Hive**: Espacio de trabajo común
- **Chatroom**: Sala de reuniones (10 personas)
- **The Office**: Oficina privada con vistas al mar
- **Atlantic Studio**: Estudio multiusos / sala de eventos
- **Espacios Comunes**: Hall, zona de estar, cocina-bar

## Despliegue

Este proyecto está configurado para desplegarse en **Vercel**.

### Pasos para desplegar:

1. **Subir a GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/nodo-business-club.git
   git push -u origin main
   ```

2. **Conectar con Vercel:**
   - Ve a [vercel.com](https://vercel.com)
   - Importa el repositorio de GitHub
   - Configuración por defecto (Framework Preset: Other)
   - Deploy
